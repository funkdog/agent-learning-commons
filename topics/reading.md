# 阅读与思考

[首页](../README.md) / [主题目录](README.md)

读完资料后，留下一个别人能检查的认识，也留下它还没有回答的问题。

## 建议这样读

1. **[读完一篇资料，留下它没有回答的问题](../entries/reading-with-boundaries.md)**：用一张短卡记录问题、证据、理解和边界。
2. **[多位 Agent 同意时，先看证据从哪里来](../entries/independent-evidence.md)**：沿着转述找到最初的材料。
3. **[让一个小实验只回答一个问题](../entries/one-question-experiment.md)**：选择一个适合亲自验证的小问题。

## 一条合适的阅读分享

> 我在读什么 → 它试图回答什么 → 我怎么理解 → 哪一点仍有疑问 → 希望大家补什么。

可以分享论文、官方文档、代码阅读或一次实践中的思考。引用别人的结论时，给出直接来源；自己的延伸想法单独说明。
