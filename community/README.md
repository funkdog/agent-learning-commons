# 在讨论区接着想

[返回首页](../README.md) · [贡献指南](../CONTRIBUTING.md)

打开本仓库上方的 **Discussions**，选择 **New discussion**，再按下面的用途选择分类。分类用固定英文名匹配 GitHub 表单，说明和投稿内容使用中文。

| 分类 | 适合什么内容 | 提交后希望发生什么 |
| --- | --- | --- |
| General · 探索笔记 | 阅读心得、实践发现、尚未成熟的思考 | 别人补充视角、来源或问题 |
| Q&A · 提问求助 | 已尝试但仍没弄懂的问题 | 得到解释，或找到下一步可以查什么 |
| Show and tell · 实验与复现 | 实际执行过的验证、负结果和反例 | 别人能检查条件、尝试复现 |

如果看不到 Discussions 标签或上述分类，说明仓库尚未完成[原生设置](../maintainers/SETUP.md)。模板文件已经准备好，但需要启用讨论区并创建匹配分类后才能显示。

## 主题与分类分开

分类说明这次在做什么；主题说明在研究什么。主题先使用“记忆与上下文、评测与实验、多 Agent 协作、阅读与思考”。

投稿表单会询问主题，但选择主题不会自动变成 GitHub 标签。维护者可补充对应标签；熟悉内容后，可以把常用主题筛选保存为浏览器书签。

## 发布一条有上下文的分享

第一段说明当前问题，不要求每次都给出结论。告诉别人哪些是你实际看到的，哪些是自己的解释，以及最希望大家接续哪一步。

想验证但尚未运行的实验计划，放在 General 或 Q&A；完成后再到 Show and tell 分享记录，并互相链接。

## 回复时留下新增的东西

可以补一手来源、给具体例子、提出反例、指出一个条件差异，或者整理长讨论的进展。不必每次都总结所有人，也不必为表示参与而重复已有回答。

围绕观点和证据交流，不评价参与者的人格。对解释有分歧时，先说明需要什么新材料才能区分它们。

## 从讨论到文章

讨论形成可复用的内容后，由参与者整理为[知识条目](../templates/entry.md)，保留来源、不同意见和原讨论链接，通过 PR 进入仓库。合入后，在原讨论回填文章链接。

**还没有结论，也可以继续留在讨论中。** 不要求每条讨论都转成文章。
