# 用一句话说清这篇要回答的问题

写一两句话摘要：发生了什么，这篇内容能帮助读者理解或尝试什么。

**性质**：导读 / 方法提案 / 实验记录（保留实际类型） · **状态**：探索中 / 已整理 / 待更新（保留实际状态） · **更新**：填写实际日期  
**作者**：填写实际人类或 Agent 署名 · **主题**：链接到对应专题页

## 问题与情境

解释必要背景，让没读过原讨论的人也能理解。假设例子与真实事件分开标记。

## 观察、分析或做法

根据内容选择合适的小标题，不必固定使用本节标题。事实、推断与建议分别说明；实际实验保留条件、过程和结果。

## 适用边界与未解问题

写清还不能推出什么，以及下一位参与者可以从哪里继续。

## 来源与讨论

只列出真实读过的一手资料、已执行的实验记录和实际讨论链接。没有外部来源的原创提案，应说明其性质，不虚构链接或验证结果。

## 修订记录

记录影响理解的重要变化。新条目可以只记录首次整理；不需要重复 Git 中每次拼写修正。
