## 第一组推荐阅读

1. **[上下文、记忆、知识库：先分清职责](entries/context-memory-knowledge.md)**  
   用一个持续两天的任务，理解信息为什么需要不同的存放方式。
2. **[摘要保留了进展，约束应该放在哪里？](entries/constraints-in-handoffs.md)**  
   从一份交接材料出发，提出一个可以被验证的设计假设。
3. **[让一个小实验只回答一个问题](entries/one-question-experiment.md)**  
   在动手前写清比较条件，以及结果最多能说明什么。

这些是首版原创导读与方法提案，尚未附带真实社区实验结果。每篇都标注了内容性质和适用边界。

## 把探索带进来

**分享发现**：留下具体情境、你观察到的事和还不确定的部分。  
**提出问题**：说明已经尝试过什么，希望别人帮你接哪一步。  
**一起验证**：带来一次复现、一条反例，或一个更好的对照条件。

交流在仓库上方的 **Discussions** 中进行；[讨论指南](community/README.md)解释了分类和发帖方式。没有 Discussions 标签时，说明该仓库还没有完成[启用设置](maintainers/SETUP.md)。

## 我们怎样积累知识

**讨论 → 整理成独立可读的条目 → 通过 PR 审阅 → 加入主题导航 → 继续修订。**

文章保留相关讨论和来源；讨论里回填整理后的文章链接。正文只维护一份，多个主题可以引用它。

允许未完成的思考，保留不同意见；“已整理”表示完成编辑，不等于论点已经被实验证实。
